独立打开

先配置，再开始聊天。 页面就绪只代表程序已启动，模型和账号还需要你设置。

  1. 在「记忆与任务」中配置模型，并启用 astrbot 回传频道。
  2. 在「聊天与插件」中添加微信；QQ 在「QQ 登录」中扫码，再连接 AstrBot。
  3. 在微信或 QQ 发送 /paw whoami，把自己的 ID 填入桥接插件的允许用户列表。

三个页面保留各自登录与设置。切换标签不会主动重新加载页面。
