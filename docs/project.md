# 项目目标与路线

AstrBot-QwenPaw 是独立维护的社区集成项目，连接 AstrBot 的聊天平台与插件生态、QwenPaw 的个人助手能力，以及可选的 NapCat QQ 接入。

当前发布阶段为 **0.5.0-alpha**。上游程序保留各自原生后台、版本和许可，集成代码负责消息路由、工具调用、身份与工作区边界、任务结果回传及启动部署。

## 当前范围

- Windows Docker Desktop 上的双击启动与一个本机网页入口。
- 独立个人助手、私聊与群会话隔离、显式跨平台绑定。
- 手动记忆管理、原生记忆检索，以及由配置模型驱动的自动记忆。
- 结构化浏览器、个人工作区文件与受控的 AstrBot 模型工具调用。
- 图片、文件、视频、音频的桥接及按实际平台能力回传。
- 保留数据的停止与启动、权限校验、协议回归和隐私白名单打包。

## 后续优先事项

1. 完善第一次配置指引，让模型、扫码登录与管理员设置更容易完成。
2. 为 Linux 串起完整的启动与健康检查，补充公网 HTTPS 和外层认证的明确部署模板。
3. 在独立空目录持续验证新装、升级、备份与恢复，扩大已验证的平台和模型组合。
4. 改善任务进度、失败诊断及资源使用说明，逐项验证第三方插件。

测试通过的范围见[验证说明](validation.md)。页面就绪、协议回归和真实模型长期记忆质量是不同的验收层级；公开测试版不承诺所有模型、插件和网站均兼容。
