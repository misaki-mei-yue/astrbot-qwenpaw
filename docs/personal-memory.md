# 微信和 QQ 中的个人助手

AstrBot 负责消息与插件，QwenPaw 负责独立助手、原生记忆与任务。每个获授权账号拥有自己的工作区；同一人的微信与 QQ 可以显式绑定。管理仍使用两套程序的原生后台。

## 先配置模型与权限

1. 在 AstrBot 中连接平台，向机器人私聊发送 `/paw whoami`，将返回 ID 加入桥接允许列表。
2. 在 QwenPaw 为模板 Agent（默认 `default`）配置有效模型。`QWENPAW_AGENT_ID` 是创建个人助手时的模板，不是所有用户共用的记忆空间。
3. 发送 `/paw status` 查看个人助手 ID。首次普通聊天或手动记忆操作会创建 `abp_...` 助手；在原生 Console 选择这个 ID 管理它。

已有个人助手保留各自模型设置。后来修改模板不会覆盖它们，必要时在对应助手的模型页修改。未配置模型时会明确提示，手动记忆命令仍可使用。

## 常用命令

| 命令 | 效果 |
|---|---|
| `/paw whoami` | 查看平台用户身份，供管理员授权。 |
| `/paw status` | 查看当前助手、接收会话及工具状态。 |
| `/paw remember 我喜欢简洁的中文回答` | 保存一条明确备注，等待原生检索索引同步。 |
| `/paw memory`、`/paw memory 2` | 分页查看手动备注，每页 10 条。 |
| `/paw correct 记忆ID 新内容` | 更正指定备注。 |
| `/paw forget 记忆ID` | 清空指定备注。 |
| `/paw new` | 新建对话，保留长期记忆；旧会话任务需重新选目标。 |
| `/paw link` | 在私聊生成跨平台绑定码。 |

手动备注最多保存 200 条有效记录，每条最长 8000 字符。`/paw memory` 只列出这些明确备注，自动提炼的日常／整理记忆在对应 Agent 的原生后台查看。

删除一条备注不会删除历史聊天，也不保证删除模型另外提炼的记忆副本。索引由原生 watcher 异步同步，更新后可能短暂召回旧内容；刷新失败时先查备注是否已经写入，不要反复保存。

## 绑定自己的微信与 QQ

在希望保留个人助手的**源账号私聊**发送 `/paw link`，再把回复中的完整 `/paw link 绑定码` 发到另一个已授权账号的私聊。绑定码 10 分钟有效，只能成功兑换一次，不要发到群里。

建议先绑定，再在目标账号建立独立记忆。目标已经有独立工作区或其他绑定关系时，系统会拒绝自动合并，保留已有数据。相同数字 ID 跨平台不会自动视为同一个人。

绑定只影响私聊。群中按群和发送者分配独立 `abg_...` 工作区，不带入私聊记忆，也不与同群其他成员共用记忆。群回复仍对群成员可见。

## 自动记忆和长期召回

自动提炼与召回使用 QwenPaw 原生 ReMe 机制。新个人助手继承模板的自动记录配置并启用召回；没有 embedding 模型时可使用原生 BM25。自动提炼需要有效模型，结果质量取决于模型与配置。

建议用无敏感内容测试：说明一种偏好，继续聊几轮，等待原生记忆处理后新建会话，再询问该偏好；随后更正它并确认过时信息不会继续主导回复。不要把手动备注检索成功当作自动形成准确用户画像的证明。

## 文件、浏览器、插件与任务

- **文件：** 读取、写入、编辑本助手的普通工作文件，以及当前合法会话附件目录。资料放在独立子目录，搜索时缩小范围，避免递归扫描含配置的工作区根。
- **浏览器：** `astrbot_browser` 提供打开、读取、点击、填写、状态和关闭。不同助手的 Cookie 分开，使用容器内临时浏览器；不接管宿主已有浏览器，不提供文件上传、下载或持久登录资料。
- **插件：** 原 AstrBot 命令继续由原插件处理。只有当前消息可用且被管理员放行的模型工具，才可由 QwenPaw 调用。
- **主动任务：** 在本人 Agent 的任务页选择 `astrbot` 频道及 `/paw status` 对应会话，使用 `final`、工具安全和共享会话设置。可以回传结果与受检文件，不能借用已结束的 AstrBot 消息调用插件工具。

受管助手禁用任意 shell、任意 Python 浏览器、跨助手委派及未经审核的工具。守卫检查身份和路径，拒绝配置、凭据、插件目录、越界路径与链接。**这是工具调用层边界，不是操作系统级沙箱**；管理后台应只交给可信管理员。详见[安全说明](../SECURITY.md)。

## 接续已有 AstrBot 上下文

将旧 AstrBot 数据放回 AstrBot，不会自动把人设与历史复制给新 QwenPaw 助手。需要明确选定来源私聊、目标个人助手与归属关系，不能把共享历史或其他人的内容自动导入。

提供 `scripts/import_astrbot_legacy_context.py` 与 `scripts/rebuild_imported_qwen_history.py` 作为高级离线迁移工具。前者默认预演，从已升级为 v4 的离线副本读取，应用时要求独立备份及停止相关 QwenPaw；后者需在匹配的 QwenPaw 环境中验证并重建原生历史索引。先阅读各自 `--help`，核对脚本支持的基线，遇到不匹配应停止。

迁移保留来源原文和防重标记，不自动捏造偏好或覆盖其他用户数据。迁入后仍需确认人设实际载入，等待文件扫描，并验证原生检索；仅“重建接口完成”不保证新文件已经入库。迁移档案和报告属于私密运行数据，不应随项目发布。

## DeepSeek Responses 兼容

QwenPaw 自动检索可能生成程序模拟的工具轮次，其中没有模型生成的思考内容。官方 DeepSeek Responses 思考模式要求相应工具回放携带 `reasoning_text`，直接发送这种模拟轮次可能返回 400。

桥接中间件仅将带完整原生来源标记的自动检索结果转换为普通参考资料，保留原文并标注其中指令不应执行；保留真实模型思考、工具调用与存储历史。其他提供商不套用此适配，不关闭思考，也不自动重复提交失败任务。

这项兼容不保证任意中转服务或未来协议都一致。失败时查看原生后台错误，报告问题前移除账号、口令、聊天与附件内容。
