# 在微信和 QQ 中使用个人助手

本次代码把 AstrBot 的聊天接入 QwenPaw 的独立助手。每个人拥有自己的记忆、文件工作区和浏览器上下文；同一人的微信与 QQ 可以主动绑定。继续使用两套程序的原生后台。

## 先配置，后聊天

1. 启动组合包，打开 `http://localhost:18080/`。在 AstrBot 配置微信 / QQ，并将自己的用户 ID 加入桥接的允许列表；`/paw whoami` 可以显示 ID。
2. 在 QwenPaw 原生后台配置模型提供商和默认模型。桥接的 `QWENPAW_AGENT_ID`（默认 `default`）现在是创建个人助手时的配置模板，不再承接所有人的聊天。模型密钥仍由 QwenPaw 管理。
3. 如果要让微信和 QQ 共用个人记忆，优先完成下面的账号绑定，再开始两边的独立聊天。
4. 在私聊发送 `/paw status` 查看自己的助手 ID。首次聊天或手动记忆操作会创建对应的 `abp_...` 助手；后台用这个 ID 选择助手，查看它的模型、记忆、文件和任务。

没有模型时，聊天会明确提示尚未配置，不会偷偷切换到默认助手。手动记忆可以先使用。已有个人助手保留自己的模型设置；后来修改模板不等于更新所有已有助手，必要时在对应助手的模型页设置。

## 绑定自己的微信和 QQ

在希望保留记忆的账号与机器人的**私聊**里发送：

```text
/paw link
```

把回复中的完整 `/paw link 绑定码` 发到另一个已获授权账号与机器人的私聊。绑定码 10 分钟有效、只能使用一次。两个平台中的数字 ID 相同不会自动认为是同一个人。

绑定目标已经创建过独立个人工作区，或已有其他绑定关系时，会拒绝自动合并，避免覆盖记忆。原来的默认助手历史也不会被自动复制给任何新用户。绑定影响私聊，群中的记忆与接收会话保持原样。

## 记忆怎么用

| 命令 | 效果 |
|---|---|
| `/paw remember 我喜欢清淡的茶` | 把明确备注写入本人的 QwenPaw 记忆文件，等待原生检索索引同步 |
| `/paw memory`、`/paw memory 2` | 分页查看手动备注及其编号，每页 10 条，长内容显示摘要 |
| `/paw correct 记忆ID 我现在更喜欢红茶` | 更正指定备注，检索索引随后同步 |
| `/paw forget 记忆ID` | 清空指定备注，检索索引随后同步 |
| `/paw new` | 开始新对话，保留长期记忆；旧会话的主动任务需重新选接收会话 |
| `/paw status` | 查看个人助手 ID、接收会话和工具放行状态 |

这些命令无需模型。QwenPaw 的**自动提炼和自动召回**则使用其原生记忆机制：新助手继承模板的自动记录间隔，并启用召回。配置模型后，还需要验证它是否准确记住偏好、纠正过时信息、隔天或新会话中召回。

`/paw memory` 只列出桥接手动保存的备注，最多保存 200 条有效备注，每条最长 8000 字符；自动提炼的日常记忆和整理记忆在该助手的原生记忆页面查看。`forget` 只删除指定备注，不代表聊天记录及其他自动提炼副本也被删除。文件会立即更新，搜索索引由 QwenPaw 异步同步；期间可能短暂召回旧内容。没有 embedding 模型时使用原生 BM25 索引。如果刷新接口报错，会保留已写入的备注编号并提示刷新请求未完成，此时先查看状态，不要反复保存相同内容。

群中每名用户、每个群分别使用 `abg_...` 工作区。群里不会自动带入该用户的私聊记忆；群回复本身仍然对群成员可见。

## 文件、浏览器、插件和主动任务

- **文件：** 使用 QwenPaw 文件工具读取、写入、编辑自己的工作区，或当前会话的附件目录。普通资料建议放在 `documents/` 等子目录；搜索指定资料或记忆子目录，不能递归扫描含配置的整个工作区。
- **浏览器：** 个人助手使用 `astrbot_browser` 打开公网网页、读取文字、点击和填写；不同助手的 Cookie 分开，不接管电脑已有浏览器。临时上下文不持久保存登录状态，最多同时保留 8 个，使用完可关闭。文件上传、下载、私网地址和任意代码执行暂不开放。
- **AstrBot 插件：** 原有指令仍由原插件处理。只有管理员放行、当前会话可用的模型工具，才可以被 QwenPaw 查询和调用；不是每一个插件都自动变成模型工具。
- **主动任务：** 在本人 QwenPaw 助手的任务页创建，选择 `astrbot` 频道及 `/paw status` 对应的接收会话，使用最终结果发送和工具审批。任务能使用受控的 QwenPaw 工具并回传结果；不能借用已经结束的 AstrBot 消息来调用插件工具。具体配置见 [QwenPaw 说明](qwenpaw.md)。

受管个人助手关闭原生任意 Python 浏览器、任意 shell、跨助手委派及全局修改工具。保留这些入口会破坏个人记忆隔离；工作区守卫同时拦截越界路径、链接和未知工具。它属于工具参数检查，并非操作系统级多租户沙箱；部署者仍需审查安装的第三方代码。网站操作是否适当仍应遵守用户的实际请求。

模板中的可用共享 Skills 可以安装到个人助手；官方共享技能池里不存在的本地技能不会自动复制。不要把它理解为所有技能和插件均已兼容。

## 升级和测试边界

升级需要同时更新两个桥接插件。旧数据库中的共享助手路由保留为历史信息，第一次进入新版个人路由时会生成新会话；旧任务目标需重新选择。已有记忆文件不会被自动搬家或删除。内部 runtime token 用于个人助手管理签名，轮换后需由管理员迁移签名；身份不匹配时会拒绝接管旧助手。

本轮按“先补代码和自动测试，模型稍后配置”执行。自动测试包含两个用户、群聊、账号绑定、重启、明确备注的真实索引检索、文件工具边界和真实 Chromium 操作。真实模型的自动记忆提炼质量、微信 / QQ 实际送达及每个第三方插件，仍需配置后验收。新代码尚未据此更新正在运行的正式组合容器。
